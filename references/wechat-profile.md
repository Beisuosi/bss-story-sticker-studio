# 微信投稿配置

依据2026-11-07用户保存的微信官方制作规范快照；发布skill时没有重新取得完整审核标准。使用前核实官方后台更新。

官方入口：https://sticker.weixin.qq.com/cgi-bin/mmemoticon-bin/readtemplate?t=home/index

|内容|要求（快照）|
|---|---|
|动态专辑|8～24任意张数，GIF，240×240，每张≤500KB，循环、节奏流畅|
|详情横幅|750×400，JPG/PNG，≤500KB，避免文字、白底和透明|
|封面|240×240 PNG，≤500KB，透明，宜半身/全身，简洁无字无白描边|
|聊天图标|50×50 PNG，≤100KB，透明，宜头部，简洁无白描边|
|专辑名称|≤8汉字，无标点空格|
|介绍|≤80汉字|
|版权署名|≤10汉字；没有登记则填写真实设计师/工作室署名，不能伪造登记|
|含义词|≤4汉字，普通话、避免标点和重复|

快照的聊天GIF部分没有固定帧数或帧率条款。“24帧以内、固定12帧/秒”属于自拍特效，不能套用。GIF参数合格不证明视觉流畅或内容过审；脚本保守用500000/100000字节检查。

不透明故事场景并非该快照明文禁止；透明要求明确针对封面与图标，别把去背景强加到所有动图。

艺术家头像640×640、≤500KB；艺术家横幅750×400、≤80KB；赞赏引导图750×560、致谢图750×750，GIF/PNG、≤500KB，均为另外用途，不混作专辑封面。赞赏开通取决于账户条件、资料审核和协议，不因生成图片就已开通。

粗口、谐音、破坏性喜剧等需结合完整审核标准判断。只见制作规范时不能冒称官方明确禁了某个词。尊重用户原文案试审选择，保留风险判断与真实审核结果。
